# NEWSFLOW APP

baseUrl: http://localhost:8080

## 1、文章列表

/article/list

参数：

page: [Int]  
keyword: [String], (required=false)

返回：

```
{
    list: [
        {
            articleId: [Long],
            wallImage: [String],
            title: [String],
            categoryName: [String],
            publishTime: [String]
        }
    ],
    isEnd: [Boolean]
}
```

publishTime 格式为 MM-dd，isEnd 为 true 表示没有下一页。

## 2、文章详情

/article/info

参数：

articleId: [Long]

返回：

```
{
    articleId: [Long],
    coverImages: [String[]],
    title: [String],
    author: [String],
    content: [String],
    publishTime: [String],
    categoryImage: [String],
    categoryName: [String],
    categoryDescription: [String]
}
```

publishTime 格式为 yyyy-MM-dd。

## 3、分类列表

/category/list

参数：无。

返回：

```
{
    list: [
        {
            categoryId: [Long],
            name: [String],
            image: [String],
            description: [String]
        }
    ]
}
```

# NEWSFLOW CONSOLE

baseUrl: http://localhost:8081

/article/list

参数：

page: [Int]  
keyword: [String], (required=false)

返回：

```
{
    list: [
        {
            articleId: [Long],
            wallImage: [String],
            title: [String],
            categoryName: [String],
            publishTime: [String],
            createTime: [String],
            updateTime: [String]
        }
    ],
    total: [Long],
    pageSize: [Int]
}
```

publishTime、createTime、updateTime 格式为 yyyy-MM-dd HH:mm:ss。

## 3、文章新增

/article/create

参数：

coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [String]  
categoryId: [Long]

publishTime 格式为 yyyy-MM-dd。

返回：

数据的id or 失败信息
