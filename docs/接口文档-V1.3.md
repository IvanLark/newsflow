# NEWSFLOW APP

baseUrl: http://localhost:8080

## 1、文章列表

/article/list

参数：

page: [Int]  
keyword: [String], (required=false)

返回：

```
{
    list: [
        {
            articleId: [Long],
            wallImage: [String],
            title: [String],
            publishTime: [String]
        }
    ],
    isEnd: [Boolean]
}
```

publishTime 格式为 MM-dd，isEnd 为 true 表示没有下一页。

## 2、文章详情

/article/info

参数：

articleId: [Long]

返回：

```
{
    articleId: [Long],
    coverImages: [String[]],
    title: [String],
    author: [String],
    content: [String],
    publishTime: [String]
}
```

publishTime 格式为 yyyy-MM-dd。

# NEWSFLOW CONSOLE

baseUrl: http://localhost:8081

## 1、文章列表

/article/list

参数：

page: [Int]  
keyword: [String], (required=false)

返回：

```
{
    list: [
        {
            articleId: [Long],
            wallImage: [String],
            title: [String],
            publishTime: [String],
            createTime: [String],
            updateTime: [String]
        }
    ],
    total: [Long],
    pageSize: [Int]
}
```

publishTime、createTime、updateTime 格式为 yyyy-MM-dd HH:mm:ss。

## 2、文章详情

/article/info

参数：

articleId: [Long]

返回：

```
{
    articleId: [Long],
    coverImages: [String[]],
    title: [String],
    author: [String],
    content: [String],
    publishTime: [String],
    createTime: [String],
    updateTime: [String]
}
```

publishTime、createTime、updateTime 格式为 yyyy-MM-dd HH:mm:ss。

## 3、文章新增

/article/create

参数：

coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [Int]

返回：

数据的id or 失败信息

## 4、文章修改

/article/update

参数：

articleId: [Long]  
coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [Int]

返回：

数据的id or 失败信息

## 5、文章删除

/article/delete

参数：

articleId: [Long]

返回：

成功 or 失败
