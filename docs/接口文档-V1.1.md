# NEWSFLOW APP

baseUrl: http://localhost:8080

## 1、文章列表

/article/list

参数：

无

返回：

```
{
    list: [
        {
            articleId: [Int],
            wallImage: [String],
            title: [String],
            publishTime: [Int]
        }
    ]
}
```

## 2、文章详情

/article/info

参数：

articleId: [Int]

返回：

```
{
    articleId: [Int],
    coverImages: [String[]],
    title: [String],
    author: [String],
    content: [String],
    publishTime: [Int]
}
```

# NEWSFLOW CONSOLE

baseUrl: http://localhost:8081

## 1、文章新增

/article/create

参数：

coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [Int]

返回：

自增id为：xxx or 失败

/article/update

参数：

coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [Int]

返回：

成功 or 失败

## 3、文章删除

/article/delete

参数：

articleId: [Int]

返回：

成功 or 失败
