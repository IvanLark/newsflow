# NEWSFLOW APP

baseUrl: http://localhost:8080

## 1、文章列表

/article/list

参数：

无

返回：

```
{
    list: [
        {
            articleId: [Long],
            wallImage: [String],
            title: [String],
            publishTime: [String]
        }
    ]
}
```

publishTime 格式为 MM-dd。

## 2、文章详情

/article/info

参数：

articleId: [Long]

返回：

```
{
    articleId: [Long],
    coverImages: [String[]],
    title: [String],
    author: [String],
    content: [String],
    publishTime: [String]
}
```

publishTime 格式为 yyyy-MM-dd。

# NEWSFLOW CONSOLE

baseUrl: http://localhost:8081

## 1、文章新增

/article/create

参数：

coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [String]

publishTime 格式为 yyyy-MM-dd。

返回：

自增id为：xxx or 失败

## 2、文章修改

/article/update

参数：

articleId: [Long]  
coverImages: [String]  
title: [String]  
author: [String]  
content: [String]  
publishTime: [String]

publishTime 格式为 yyyy-MM-dd。

返回：

成功 or 失败

## 3、文章删除

/article/delete

参数：

articleId: [Long]

返回：

成功 or 失败
